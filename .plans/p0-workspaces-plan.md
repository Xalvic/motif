# P0: move to npm workspaces (proposal)

Status: done 2026-10-29, approved by the owner. Changes from the proposal:

- `tests/state/idea.test.ts` stays in `apps/web`. It uses the listening-pass plan from `apps/web/src/state/listening.ts`.
- `newSeed` uses `Math.random`, so it moved from `idea.ts` into the web store. Core now has no `Math.random`.
- `tsconfig.scripts.json` became `packages/core/tsconfig.node.json`. It covers `scripts` and `tests`, which run in Node (`structuredClone`). Core `src` keeps a tsconfig with no DOM and no Node types.
- The 3 Prettier warnings on the transition tables existed before the move. They are not fixed here.

Goal: the same app in two workspaces. No behaviour change. All tests, typecheck, lint and build pass after each commit.

## Scope

- P0 creates `packages/core` and `apps/web` only.
- `packages/protocol` and `apps/server` start in P2, when they get their first code. Empty folders now give no value.

## Target layout

```
package.json            workspaces: ["packages/*", "apps/*"]; dev tools; scripts that delegate
tsconfig.base.json      shared compiler options (from today's tsconfig.json)
eslint.config.js        one config for all workspaces
vitest.config.ts        test.projects: ["packages/*", "apps/*"]: one run, one total
packages/core/          name @motif/core
  package.json          deps: tonal. exports: { "./*": "./src/*.ts" }
  tsconfig.json         lib ES2023 only, no DOM
  tsconfig.scripts.json node types, for scripts/
  src/theory/**         from src/theory (data JSON included)
  src/idea.ts           from src/state/idea.ts (pure: imports theory only)
  scripts/chordonomicon from scripts/chordonomicon
  tests/theory/**       from tests/theory (golden file included)
  tests/scripts/**      from tests/scripts
  tests/idea.test.ts    from tests/state/idea.test.ts
apps/web/               name @motif/web
  package.json          deps: react, react-dom, tone, smplr, zustand, idb-keyval,
                        @tonejs/midi, midi-file, tonal, @motif/core
  tsconfig.json         DOM lib, vite/client types
  vite.config.ts        from root
  index.html, spike.html, timing.html
  src/{audio,state,ui,main.tsx}
  tests/{audio,state}   minus idea.test.ts
```

Import change in web: `'../theory/roman'` becomes `'@motif/core/theory/roman'`. `'../state/idea'` becomes `'@motif/core/idea'`. No barrel file in P0. A public API for core can come in P1.

## What stays the same

- Code inside `src/theory` does not change. Its relative imports keep working.
- `scripts/chordonomicon` keeps its relative paths: `../../src/theory/roman.ts` and the output folder resolve to the same files.
- Theory tests keep their relative paths (`../../src/theory/...`).
- Storage keys stay `chord-spark`. No storage code changes.
- Root commands stay the same: `npm run dev | test | typecheck | build | lint | format | tables`.
- `.claude/launch.json` keeps `npm run dev` on port 5173.
- Dependency versions do not change. Only their `package.json` home changes.

## Gains

- `packages/core` typechecks without the DOM lib. The compiler then enforces "no DOM in theory".
- An ESLint `no-restricted-imports` rule stops core from importing `@motif/web`, React, Tone or smplr.

## Commits

Each commit runs `npm test`, `npm run typecheck`, `npm run lint` and `npm run build` before it is made.

1. **Extract core.** Add root `workspaces`. `git mv` theory, idea, scripts and their tests into `packages/core`. Rewrite web imports to `@motif/core/...`. The app stays at the root for this commit.
2. **Move web.** `git mv` the app files into `apps/web`. Split dependencies. Make the root scripts delegate. Move the gitignored Chordonomicon CSV with a plain move.
3. **Docs.** Update the CLAUDE.md layout, `.claude/rules/*.md` paths, a `decisions.md` entry, and path names in SPEC, THEORY, AUDIO, README and CREDITS. Do not edit history in `docs/progress/LOG.md`.

## Edits that are not pure moves

- `vite.config.ts`: the listening-pass plugin resolves `docs/progress/listening` from the current folder. Under `apps/web` that path breaks. It must resolve from the repo root (`import.meta.dirname` + `../../docs/...`).
- `eslint.config.js`: the `Math.random` rule path becomes `packages/core/src/**`. Ignores become `**/dist`.
- `.gitignore`: `scripts/chordonomicon/data/` becomes `packages/core/scripts/chordonomicon/data/`.
- `package-lock.json`: regenerated by `npm install`.

## Risks

- `git log --follow` is needed to see file history after the moves.
- Vite must serve TS source from a linked workspace. This is normal, but check the dev server and the build.
- Two `tonal` users (core and web `export-midi.ts`) must resolve to one copy. npm hoists it, so this is expected.
